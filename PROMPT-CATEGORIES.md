# Blackmount AI — Разделы страницы «Промпты»

> Этот файл описывает новые категории для страницы промптов.
> Только визуальные промпты (фото + видео). Текстовых нет.
> 30 категорий: 20 основных + 5 актуальных тем + 5 классических тем.
> Используй для замены текущих заглушечных категорий в проекте.

---

## UX: Навигация по разделам

Сверху страницы — горизонтальная полоса с кнопками-фильтрами (chips/tabs).
Видны первые 7 разделов + кнопка «Все разделы».
По нажатию «Все разделы» — открывается выпадающая панель (dropdown/modal) с полным списком всех 30 разделов в виде сетки с иконками.
Активный раздел подсвечивается. Повторный клик по «Все разделы» закрывает панель.

### Порядок в горизонтальной полосе (первые 7 + кнопка):
1. Все
2. Тренды
3. Праздники
4. Фотосессии
5. Стилизации
6. Оживление фото
7. Спецэффекты
8. [Кнопка «Все разделы» с иконкой сетки/grid]

## Категории (30 штук)

### 1. Все
- slug: `all`
- Описание: Все промпты без фильтра
- Показывается по умолчанию

### 2. Тренды
- slug: `trends`
- Описание: Самые популярные и вирусные промпты прямо сейчас
- Источник: подборка вручную, обновляется

### 3. Праздники
- slug: `holidays`
- Описание: Новый год, 8 марта, 14 февраля, 23 февраля, День рождения, 1 сентября
- Меняется сезонно

### 4. Фотосессии
- slug: `photoshoots`
- Описание: Деловой стиль, уличное фото, студийные портреты, летние, семейные

### 5. Портреты и аватарки
- slug: `portraits`
- Описание: Аватарки для Telegram/VK/Instagram, профессиональные фото, селфи

### 6. Стилизации
- slug: `stylizations`
- Описание: Пиксар, Disney, Love Is, GTA, комиксы, ретро, СССР, русский народный

### 7. Открытки и поздравления
- slug: `cards`
- Описание: Персональные открытки, поздравления, живые открытки

### 8. Оживление фото
- slug: `animate`
- Описание: Говорящие фото, танцующие портреты, живые открытки, lip sync

### 9. Спецэффекты
- slug: `effects`
- Описание: Взрывы, магия, левитация, жидкий металл, огонь, вода, элементы

### 10. Движения камеры
- slug: `camera`
- Описание: Дрон, crash zoom, панорама, 360° облёт, dolly, bullet time

### 11. Кинематограф
- slug: `cinema`
- Описание: Кинематографичные сцены, эпичные кадры, замедленная съёмка

### 12. Реклама
- slug: `commercial`
- Описание: Промо товаров, packshot, продуктовые ролики, баннеры

### 13. Reels и TikTok
- slug: `reels`
- Описание: Вертикальные видео, вирусные форматы, трендовые шаблоны

### 14. Музыка и клипы
- slug: `music`
- Описание: Анимация под музыку, караоке, танцы, перформансы

### 15. Мемы
- slug: `memes`
- Описание: Смешные анимации, пародии, ситуативный контент

### 16. Фотореализм
- slug: `photorealism`
- Описание: Продуктовая съёмка, еда, интерьеры, пейзажи, предметы

### 17. Арт и фэнтези
- slug: `art`
- Описание: Концепт-арт, фэнтези, sci-fi, киберпанк, сюрреализм

### 18. Аниме
- slug: `anime`
- Описание: Аниме-портреты, манга, японская анимация

### 19. Дизайн и бренд
- slug: `design`

## Структура данных (TypeScript)

```typescript
interface PromptCategory {
  id: string;        // slug из списка выше
  name: string;      // Название на русском
  description: string; // Описание
  icon?: string;     // Путь к иконке/обложке (public/assets/prompts/category-{slug}.png)
  order: number;     // Порядок отображения (1-20)
}
```
