# Модуль: Keyboard Shortcuts (Горячие клавиши)

---

## Описание
Быстрая навигация и действия через клавиатуру. Работает на всех страницах. Модальное окно со списком клавиш по Cmd+/.

**Текущая реализация:** Полностью работает. Компонент смонтирован в layout.tsx.

## Статус реализации
- ✅ Навигация Cmd+1-6 по страницам
- ✅ CommandPalette (Cmd+K)
- ✅ Модальное окно помощи (Cmd+/)
- ✅ Escape закрывает модалки, overlay, dropdown
- ✅ Не перехватывает клавиши в input/textarea (кроме Escape и Cmd+Enter)
- ✅ Не конфликтует с браузерными шорткатами

## Горячие клавиши

### Навигация
| Клавиша | Действие |
|---------|----------|
| Cmd/Ctrl + 1 | Главная (/) |
| Cmd/Ctrl + 2 | История (/history) |
| Cmd/Ctrl + 3 | Промпты (/prompts) |
| Cmd/Ctrl + 4 | База знаний (/knowledge) |
| Cmd/Ctrl + 5 | Рейтинг (/rating) |
| Cmd/Ctrl + 6 | Арена (/arena) |

### Общие
| Клавиша | Действие |
|---------|----------|
| Cmd/Ctrl + K | CommandPalette (поиск) |
| Cmd/Ctrl + / | Список горячих клавиш |
| Escape | Закрыть модалку / overlay / dropdown |

### В чате
| Клавиша | Действие |
|---------|----------|
| Cmd/Ctrl + Enter | Отправить сообщение |
| Escape | Остановить генерацию |
| Cmd/Ctrl + Shift + C | Копировать последний ответ |

## Реализация
- Компонент: `src/components/shared/keyboard-shortcuts.tsx`
- Монтируется в: `src/app/(main)/layout.tsx`
- Модальное окно помощи: заголовок «Горячие клавиши», таблица клавиша → действие, закрытие по Escape или клику вне
